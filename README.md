# Клиент для друга

Сборка с модом States mod 1.2.9 для Minecraft **1.21.1** с **NeoForge 21.1.266**.

1. Склонируй репозиторий или скачай его на GitHub через **Code → Download ZIP** и распакуй.
2. Открой эту папку и запусти `Prepare-Client.bat`. Он соберёт MoreDiscs из трёх частей, сверит его SHA-256 и откроет папку `minecraft`.
3. Закрой Minecraft и скопируй **содержимое** папки `minecraft` в папку своего профиля. В корне профиля должны появиться `mods`, `config` и `kubejs`. Если обновляешь ранее установленную сборку, сначала перенеси её старую папку `mods` в резервную папку, чтобы в профиле остался один набор версий.
4. Запусти свой профиль NeoForge и подключись к серверу по адресу, который дал хозяин.

Команды и настройки игры описаны в [инструкции клиента](README-RU.txt) и [списке команд](КОМАНДЫ.txt).
